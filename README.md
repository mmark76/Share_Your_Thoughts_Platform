# Share Your Thoughts

**Tagline:** A social blogging platform.

`Share Your Thoughts` is a custom software project for creating, managing and hosting personal blogs. The separate Social Platform is a later phase and is not part of the current implementation.

## Current phase

The project is currently limited to the Blog App frontend:

- visual design,
- page layout,
- responsive behaviour,
- reusable components,
- typography, colours and spacing,
- article presentation.

Backend, database, authentication and social functionality are deferred.

## Approved frontend foundation

- Next.js
- React
- TypeScript
- App Router
- CSS Modules
- Modular, component-based architecture
